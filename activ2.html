Installation Home Assistant

Projet Cyber SES BTS SIO : Déploiement complet sur Raspberry Pi pour supervision domotique client.

Cyber SES BTS SIO project: Full Home Assistant deployment on Raspberry Pi for client home automation.

Étapes Installation

Raspberry Pi 5

Matériel choisi : Pi 5 + dissipateur + ventilo. Installation Home Assistant OS via Raspberry Pi Imager.

Assemblage

Montage boîtier officiel avec câbles réseau et alimentation 5V/5A. Fixation carte SD 128Go A2.

Flash OS

Écriture image Home Assistant OS v12 sur carte SD. Configuration SSH et WiFi en pré-prod.

Premier Boot

Accès http://homeassistant.local:8123. Configuration initiale utilisateur/admin et onboarding.

Configuration & Automatismes

Intégrations

Zigbee2USB + Tuya + Shelly. Détection 25 appareils : lumières, prises, capteurs température/humidité.

Automatismes

10 scénarios : lever soleil (lumières), retour maison (chauffage), nuit (sécurité). YAML + UI.

Dashboard Client

Interface Lovelace custom : cards énergie, climat, sécurité. Accès app mobile Android/iOS.

Monitoring

Addon Supervisor + MariaDB + Grafana. Logs système, uptime 99.8%, backup auto Google Drive.
